# 過去の開発履歴概要

本ファイルは、旧 `docs` 配下に蓄積されていた開発ログを現行保守向けに要約したものです。

## 2025年

- Spring Boot / PostgreSQLを利用したQ&A機能を開発
- ユーザ認証、質問、回答、いいねを実装
- 画像添付とサムネイル生成を追加
- 日本向け住所入力支援を追加
- ダークモード、レスポンシブUIを改善
- SNSリンクプレビュー / OGP取得を導入
- Docker / DevOps検証を実施
- Vue 3 / TypeScriptによるMFEメモ機能を統合し、実運用形式で検証開始

## 2026年

- Java 21へ更新
- Spring Boot 4.1.1へ更新
- Spring Securityの新APIへ追従
- PostgreSQLローカル環境を継続利用
- Lombok / Gradle / STS環境を更新
- オリジナル版とローカル開発版を分離
- 0.1として1次リファクタリングを実施
- WebP添付表示不具合を修正
- 会員情報編集機能を追加
- Webプロジェクト全体の脆弱性・依存関係を再点検
- Spring AI BOM 2.0.1へ更新
- jsoup 1.23.2へ更新
- 約1年間検証したMFEについて、現在のプロジェクト規模では保守・ビルド・構成管理コストが大きいと判断
- MFEの最終状態をGit・文書へ保存したうえで、本体からMFEアーキテクチャを撤去
- MFE撤去後、Spring Boot / Thymeleaf中心の単一Web構成としてUIとセキュリティを再整備

## 旧開発ログの扱い

`docs/` や `assets/` には過去のMFE検証資料や画面資料が残る場合があります。

これらは履歴資料であり、現在の実行アーキテクチャには含まれません。現在の仕様確認はルートREADMEおよび `doc/` 配下を優先します。
