# 変更履歴

## 0.1

### リファクタリング

- Controller / Service責務整理
- 質問添付ファイルの重複処理を統合
- リンクカードレンダリングをServiceへ分離
- Repository直接依存を削減
- `QuestionRepository` ID型を `Long` に統一
- いいね処理の重複判定を整理
- DTOの不要なJPAアノテーションを削除

### 2026-09 UI / UX改善

- ナビゲーションメニューを中央寄せに変更
- ヘッダーのPC / モバイル配置を整理
- カード、フォーム、一覧、ページングのデザインを統一
- 質問一覧をレスポンシブテーブル化
- ダークモードの背景・境界線・可読性を改善

### 2026-09 セキュリティ改善

- legacy `AttachController` を撤去
- ファイル名直接指定による表示・削除エンドポイントを削除
- 添付保存・削除パスを正規化し、アップロード領域外参照を拒否
- 質問本文のraw HTML表示経路を廃止
- CommonMark + jsoupサニタイズ後にリンクカードHTMLを合成する方式へ変更
- 不正なリンクカードURLを拒否
- jsoup 1.17.2 → 1.23.2
- Spring AI BOM 1.1.8 → 2.0.1

### MFE

- Vue / ViteベースのMFEメモ機能を本体から撤去
- `/memos/**` 配信リソースを削除
- Node.jsビルド定義を削除
- Spring Boot単体でビルド・実行可能な構成へ整理

### DB

- DBスキーマ変更なし
- PostgreSQL既存データ変更なし
