## 資料の置き場所

```text
README.md                プロジェクトの入口
doc/
├─ README.md             この目次
├─ CHANGELOG.md          変更履歴
├─ user/                 利用者向け
├─ dev/                  開発者向け（現在の仕様・手順）
└─ history/              過去の記録（書き換えない）
    ├─ records/          日付付きの作業記録
    └─ devlog/           2025年からの開発ログ
assets/                  画面画像・ER 図・動画
sql/                     SQL スクリプト
```

現在の仕様は `doc/dev/` を正とします。`doc/history/` の資料は当時の記録のため、現在の構成と異なる記述があります。
