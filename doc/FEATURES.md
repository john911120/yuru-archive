# 機能一覧

## コミュニティ機能

- ユーザ登録・ログイン・ログアウト
- 会員情報の参照・編集
- 現在のパスワード確認付きパスワード変更
- 質問の投稿、修正、削除
- 質問のタイトル・投稿者検索
- 回答の投稿、修正、削除
- 回答へのいいね
- 質問一覧での回答数表示

## コンテンツ表示

- CommonMarkによるMarkdown変換
- jsoupによるHTMLサニタイズ
- Microlinkを利用したリンクカード表示
- 不正なリンクカードURLの拒否
- 外部API取得失敗時の安全なフォールバック表示

## 添付ファイル

- 画像アップロード
- JPG / JPEG / PNG / GIF / WebP対応
- Thumbnailatorによるサムネイル作成
- 投稿修正時の添付追加・削除
- 投稿詳細画面での添付画像マウスオーバー拡大表示（左右端の画像は拡大基準点を補正し、画面外へのはみ出しを抑制）
- basename化とアップロード領域チェックによるパス保護

## UI

- Thymeleaf
- Bootstrap 5系
- ダークモード
- レスポンシブ表示
- 中央寄せナビゲーション
- カード / フォーム / 一覧UIの統一デザイン

## MFEについて

約1年間検証してきたVue / ViteベースのMFEメモ機能は、2026年9月に本体から撤去しました。

現在の実行構成にMFE機能は含まれていません。

## AIについて

Spring AI BOMは2.0.1へ更新していますが、0.1ではAI機能を実装していません。

現在は `spring.ai.model.chat=none` とし、AIモデルの自動構成を停止しています。
