# 機能一覧

## コミュニティ機能

- ユーザ登録・ログイン・ログアウト
- 質問の投稿、修正、削除
- 質問のタイトル・投稿者検索
- 回答の投稿、修正、削除
- 回答へのいいね
- 質問一覧での回答数表示

## コンテンツ表示

- CommonMarkによるMarkdown変換
- jsoupによるHTMLサニタイズ
- Microlinkを利用したリンクカード表示
- リンクカード取得失敗時の通常リンクへのフォールバック

## 添付ファイル

- 画像アップロード
- JPG / JPEG / PNG / GIF / WebP対応
- Thumbnailatorによるサムネイル作成
- 投稿修正時の添付追加・削除

## UI

- Thymeleaf
- Bootstrap 5系
- ダークモード
- レスポンシブ表示
- Vue 3 / TypeScript / Viteで作成されたMFEスタイルのメモSPA「ゆる~メスペット」（`/memos/**`、ブラウザlocalStorage使用）

### MFEメモ機能のライフサイクル

本コミットは、上記MFEメモ機能をJavaプロジェクト内部で提供する最終状態です。
機能自体は記録・検証対象として残しますが、次フェーズではJava本体から切り離し、独立したVue SPAとして管理する方針です。

## 0.1で追加していないもの

- AI文章生成
- AI回答生成
- AI要約
- AI関連投稿推薦

これらは既存機能の回帰確認後に別フェーズで検討します。
