## 1. できること

| 操作 | ログインなし | ログインあり |
|---|:---:|:---:|
| 質問一覧・詳細の閲覧、検索 | ○ | ○ |
| 添付画像の表示・ダウンロード | ○ | ○ |
| 質問の投稿・修正・削除 | - | ○（修正・削除は自分の投稿のみ） |
| 回答の投稿・修正・削除 | - | ○（修正・削除は自分の回答のみ） |
| 回答への「いいね」 | - | ○（自分の回答以外） |
| 会員情報の参照・編集、パスワード変更 | - | ○ |

ログインが必要な操作をログインせずに行うと、ログイン画面へ移動します。

## 2. 会員登録・ログイン

### 会員登録

画面上部の「会員加入」から登録します。

| 項目 | 必須 | ルール |
|---|:---:|---|
| ユーザーID | ○ | 3〜25文字。他の人と同じIDは使えません |
| パスワード | ○ | 8〜100文字 |
| パスワード確認 | ○ | パスワードと同じ値 |
| メールアドレス | ○ | メールアドレスの形式。他の人と同じアドレスは使えません |
| 郵便番号 | - | 7桁の数字（例：`1234567` または `123-4567`） |
| 住所（都道府県・市区町村・町名） | - | 郵便番号を入力して「住所検索」を押すと自動で入力されます |
| 詳細住所 | - | 255文字まで |

- 郵便番号からの住所入力には、外部サービス [ZipCloud](https://zipcloud.ibsnet.co.jp/) を利用しています。
- 管理者と誤解されやすいユーザーID（`admin` で始まるもの、`administrator`、`root`、`system`、`superuser`、`manager`、`operator`）は登録できません。大文字・小文字は区別しません。

### ログイン・ログアウト

- 画面上部の「ログイン」から、ユーザーIDとパスワードでログインします。
- ログイン中は、画面上部にユーザー名と、時間帯に合わせたあいさつ（おはようございます / こんにちは / こんばんは）が表示されます。時間帯はお使いの端末の時刻で判断します。
- ログアウトは画面上部の「ログアウト」から行います。

### ログインが制限されたとき

不正なログインを防ぐため、次の場合は一時的にログインできなくなります。

- 同じユーザーIDで、10分間に5回ログインに失敗したとき
- 同じ接続元から、10分間に合計20回ログインに失敗したとき

制限は10分後に自動で解除されます。時間をおいてから、もう一度ログインしてください。

## 3. 質問を探す

- トップページ（`/`）を開くと、質問一覧が表示されます。
- 一覧は新しい順に10件ずつ表示され、各質問の回答数も確認できます。
- 検索欄の左側で「タイトル」または「作成者」を選び、キーワードを入力して検索します。キーワードを含む質問が表示されます（部分一致）。

## 4. 質問を投稿する

ログイン後、質問一覧の「質問を登録する」から投稿します。

| 項目 | ルール |
|---|---|
| タイトル | 必須、200文字まで |
| 本文 | 必須、20,000文字まで。Markdown が使えます（[5章](#5-本文の書き方markdownリンクカード)） |
| 画像 | 任意。複数添付できます（[6章](#6-画像を添付する)） |

- 自分の質問は、質問詳細画面の「修正」「削除」から変更できます。修正画面では画像の追加・削除もできます。
- 質問を削除すると、その質問に付いた回答と添付画像も一緒に削除されます。削除した画像はURLを開いても表示されなくなります。

## 5. 本文の書き方（Markdown・リンクカード）

### Markdown

質問と回答の本文では、Markdown で書式を付けられます。

| 書き方 | 表示 |
|---|---|
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `[リンク名](https://example.com)` | リンク |
| `![説明](https://example.com/image.png)` | 外部の画像 |
| `- 項目` / `1. 項目` | 箇条書き / 番号付きリスト |
| `` `コード` `` / ```` ``` ```` で囲む | コード / コードブロック |
| `> 引用` | 引用 |

安全のため、表示できる書式には制限があります。

- 見出し（`#`）は見出しとして表示されず、通常の文字として表示されます。
- HTML タグや、スクリプトなどの危険な要素は削除されます。

### リンクカード

本文に次の形式で URL を書くと、そのページのタイトルと「原文を開く」ボタンをカード形式で表示します。

```text
[[linkcard url="https://example.com/article"]]
```

- 使えるのは `http://` または `https://` で始まる、インターネット上で公開されているページの URL です。
- 1つの投稿で表示されるリンクカードは5件までです。6件目以降は案内メッセージが表示されます。
- 相手のサイトの情報を取得できない場合や、使えない URL の場合は、カードの代わりに簡易表示になります。投稿自体は通常どおり表示されます。
- ページ情報の取得には外部サービス [Microlink](https://microlink.io/) を利用しています。
- カード内の画像と説明文の表示は、SNS 側の取得制限により2025年12月から一時停止しています。

## 6. 画像を添付する

| 項目 | ルール |
|---|---|
| 添付できる場所 | 質問のみ（回答には添付できません） |
| ファイル形式 | JPG / JPEG / PNG / GIF / WebP |
| ファイルサイズ | 1回の送信で合計10MBまで |
| 画像の大きさ | 縦・横それぞれ8,000ピクセルまで、かつ総ピクセル数4,000万まで |

- 拡張子だけを変えたファイルや、壊れた画像ファイルは受け付けません。
- 添付した画像は質問詳細画面に表示されます。マウスを重ねると拡大表示され、ダウンロードもできます。

## 7. 回答・いいね

### 回答

- 質問詳細画面の下にある入力欄から回答します。本文は10,000文字まで、Markdown が使えます。
- 自分の回答は、修正・削除できます。

### いいね

- 参考になった回答の「いいね」ボタンを押すと、いいねを付けられます（確認メッセージが表示されます）。
- 1つの回答に付けられるいいねは1人1回までです。
- 自分の回答にはいいねを付けられません。

## 8. 会員情報・パスワード

### 会員情報

画面上部の「会員情報」から登録内容を確認できます。「会員情報を編集」から次の項目を変更できます。

- メールアドレス
- 郵便番号・住所・詳細住所

ユーザーIDは変更できません。

### パスワード変更

- 会員情報画面の「パスワード変更」から、現在のパスワードと新しいパスワード（8〜100文字）を入力して変更します。
- 変更すると、変更操作をしたブラウザ以外でログインしていたセッションはすべてログアウトされます。他の端末では、新しいパスワードでもう一度ログインしてください。

## 9. 表示の切り替え

- 画面の「テーマ切替（ライト／ダーク）」ボタンで、ライトモードとダークモードを切り替えられます。
- 選んだテーマはブラウザに保存され、次に開いたときも同じテーマで表示されます。
- PC・タブレット・スマートフォンの画面幅に合わせて表示が調整されます。

## 10. 入力の上限一覧

| 項目 | 上限 |
|---|---|
| ユーザーID | 3〜25文字 |
| パスワード | 8〜100文字 |
| 詳細住所 | 255文字 |
| 質問タイトル | 200文字 |
| 質問本文 | 20,000文字 |
| 回答本文 | 10,000文字 |
| リンクカード | 1投稿あたり5件 |
| 添付画像 | 1回の送信で合計10MB、縦横8,000ピクセル、総ピクセル数4,000万 |
| ログイン失敗 | 同じIDで10分間に5回、同じ接続元で10分間に20回（超えると10分間制限） |

## 11. 困ったときは

| 症状 | 確認すること |
|---|---|
| ログインできない | ログイン失敗が続くと10分間制限されます。時間をおいて試してください |
| 突然ログイン画面に戻った | 別の端末でパスワードが変更された可能性があります。新しいパスワードでログインしてください |
| 画像を添付できない | 形式・サイズ・画像の大きさが [6章](#6-画像を添付する) の条件に合っているか確認してください |
| 住所が自動入力されない | 郵便番号を7桁で入力してから「住所検索」を押したか確認してください。ZipCloud に接続できない場合は手入力してください |
| リンクカードが表示されない | URL の形式と、1投稿5件までの上限を確認してください。相手のサイトによっては情報を取得できません |
| 見出しが大きく表示されない | 安全のため、見出しは通常の文字として表示される仕様です |
